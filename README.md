5. Ответы на вопросы:
1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?В Python переменная может сначала хранить текст. А потом туда можно записать число. В Dart так делать нельзя. Тип переменной определяется один раз при создании. Главный плюс в том. Что компилятор сразу видит ошибки и опечатки. Код не упадет во время работы у пользователя.
2. Что означает String?? Чем отличается от String?Обычный String гарантирует. Что в переменной всегда будет текст. А знак вопроса в String? разрешает переменной быть пустой. То есть принимать значение null. Это нужно для безопасности. Чтобы программа не сломалась при попытке прочитать пустые данные.
3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?Люди часто ошибаются. И договоренности в коде легко нарушить случайно. Ключевое слово final жестко запрещает менять переменную на уровне самого языка. Если кто-то попытается перезаписать такую переменную. Программа просто не скомпилируется.
4. Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.В позиционный параметр данные передаются просто по порядку. И можно перепутать местами имя и фамилию. Именованный параметр требует указывать имя аргумента при вызове. А слово required делает его строго обязательным.Пример вызова функции. describePet(name: 'Барсик', age: 3).
